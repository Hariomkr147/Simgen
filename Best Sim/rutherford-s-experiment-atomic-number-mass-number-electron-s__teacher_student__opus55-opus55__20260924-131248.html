Governing equations

F = k(2e)(Ze) / r²    with k·e² = 1.44 MeV·fm (given constant)
dmin = 2Z × 1.44 / E  fm  (head-on closest approach)
tan(θ/2) = dmin / (2b)  (b = sideways aiming distance)
A = Z + N ;   electrons = Z (neutral atom)
Shell capacity = 2n² ; first 18 elements fill K = 2, L = 8, M = 8

How the animation moves each alpha: the push away from the nucleus is F = 2·Zt·1.44 / r² (MeV per fm). Dividing by the alpha mass (3727 MeV) gives the change of speed. The position is updated in tiny time steps of 2 fm/c, 25 steps per frame. Starting speed v₀ = √(2E/m) × c. A new alpha starts at x = −400 fm every 10 frames with random b between −300 and +300 fm.

What to observe

  • Almost all alphas go straight through (green), so the atom is mostly empty space.
  • Only those aimed very close to the nucleus bounce back (red). In a real foil this is about 1 in thousands, so the nucleus is tiny, heavy and positive.
  • Raise E: dmin gets smaller and there are fewer large deflections.
  • Raise Zt: a bigger positive charge pushes harder, so more alphas are turned.
  • In the atom builder, changing N changes A but not the element or its shells.
  • Z decides the element and the number of electrons.

Common mistakes

  • "Electrons deflect the alphas." — No: electrons are about 7000 times lighter than an alpha, far too light to turn it.
  • "Mass number equals the number of electrons." — No: A = protons + neutrons.
  • "Isotopes are different elements." — No: isotopes have the same Z, so they are the same element.
  • "The nucleus fills most of the atom." — No: it is a tiny dot in the centre.
